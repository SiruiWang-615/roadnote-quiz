# Roadnote 学科练习

日中双语驾驶学科判断题练习站，使用 AI 辅助开发。GitHub Pages 从 main 根目录发布。

## 题库

25套，共1805个判断项，按共享题号识别为1716道不同题。

| 阶段 | 系列 | 套数 | 判断项 |
| --- | --- | ---: | ---: |
| 第一阶段 | 效果测定 A–G | 7 | 360 |
| 第一阶段 | 山形中央 1–8 | 8 | 400 |
| 第二阶段 | 本免模拟 1–5 | 5 | 525 |
| 第二阶段 | 原创练习 1–2 | 2 | 210 |
| 第二阶段 | 模拟考 1–3 | 3 | 310 |

461个判断项带图，212张不同图片。图片在文件内共享存储，页面加载时恢复完整数据。全部题目含中日文、参考答案与双语解析。题库按用户指示迁入，内容与现有题目编号保留；源字段摘要用于检查迁移完整性，不代表逐条核验法规时效。

第二阶段含35组图示题，每组3个判断项。本站按判断项统计，不采用正式考试图示组计分规则；整组模式统一自设30分钟。

## 功能

阶段快速选择、按系列折叠选卷、逐题即时核对、整组评分、随机5/15/30/50题、错题回练、收藏、语言切换、深浅主题、本地断点恢复及JSON备份。

随机队列依据共享题号去重，按内部语义分类轮流抽取；分类为辅助自动整理，不是官方分类。一个周期内不重复，剩余题不足不重复补题，所选范围抽完后下一次开始新周期。顺序练习和主动回练允许重复。

答题页可直接切换15/30/50题，旧组自动保存。保存退出或切换页面会暂停限时练习；恢复后继续剩余时间。首页可选择恢复任意未完成组。选卷范围会记住。结果先显示错题，可切换已答或全部题目，每次显示50项。

记录仅在当前浏览器保存，没有账号或云端同步。不同设备可导入同一JSON备份；导入会替换本地记录。清理浏览器数据会丢失记录。多标签页为最后写入覆盖，不进行并发合并。

## 运行与验证

`python3 -m http.server 8768`，浏览器访问 `http://127.0.0.1:8768/`。

`node --test core.test.cjs`：检查25套数量、1805项源字段摘要、35组图示题、图像与双语完整性、旧题号兼容、1716题整轮抽取去重、共享题号答案一致、评分与限时暂停恢复。

界面评测记录见 `QA.md`。手机浏览器使用公网部署地址；本地127.0.0.1地址只供开发电脑使用。
