# Roadnote 学科练习室

[在线体验](https://siruiwang-615.github.io/roadnote-quiz/)

一个可在手机和电脑上使用的日中双语判断题练习应用。围绕“选主题 → 练习 → 反馈 → 回练”的学习流程实现，使用 AI 辅助开发与迭代。

![Roadnote 首页](preview.png)

## 功能

- 多主题选择、顺序/随机组题、5题轻练习。
- 逐题解析和整组评分；未答题单独统计。
- 错题回练、收藏、双语题目切换、深浅色模式。
- 本地保存进度，刷新后继续；JSON 备份导入导出。
- 手机响应式布局、语义化按钮和键盘焦点状态。

## 运行与验证

无需依赖或构建工具。在项目目录运行 `python3 -m http.server 8768`，访问 http://localhost:8768 。

运行纯逻辑测试：`node --test core.test.cjs`。

`questions.js` 保存演示数据，`core.js` 负责可测试的组题/评分/进度验证，`app.js` 管理界面与本地状态，`style.css` 管理响应式布局。通过 GitHub Pages 从 main 根目录发布。

## 项目定位与限制

本项目为求职作品演示，12道题为此项目编写的通用安全意识示例，不是驾校原题、官方题库或法规解释。题目功能流程参考常见判断题练习产品，未复制参考网站的源码、页面素材或题库。

当前版本没有服务端、账号和云端同步。记录仅存在当前浏览器，清理浏览器可能丢失记录；导出备份可手动迁移。单浏览器多标签页采用最后保存版本，不提供并发合并。

面试展示建议：演示完整答题流程，说明状态存储、未答题处理、错误恢复、可测试逻辑分离及响应式取舍；按实际参与程度介绍需求设计、AI协作和验证过程。
