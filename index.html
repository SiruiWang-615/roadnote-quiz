BEHIND THE PROJECT

把一次学习体验，
做成可用的产品。

Roadnote 是一个日中双语判断题练习应用，也是一个可交互的前端作品。

从需求到功能

围绕“碎片时间练习、得到反馈、回来继续”的流程，实现主题选择、随机组题、即时解析、整组评分、错题回练与收藏。

数据与工程

题目数据与界面分离，组题、评分和记录更新作为独立纯函数测试。学习记录和中断状态保存在当前浏览器，导出备份可迁移至其他设备。

设计取舍

采用无框架静态架构，便于部署至 GitHub Pages。当前版本没有账号或云端同步，浏览器清理数据会影响本地记录，请保留备份。

开发说明

项目使用 AI 辅助编写与迭代。功能方向参考判断题练习产品的常见流程，界面和代码为此项目新建，收录四套练习题，提供题目图片与双语解析。
